# Someday

> Someday, you'll miss today.

未来の自分の視点から今日を見ることで、「今日という日」を少しだけ大切にしたくなる。
そのきっかけを届けるための、静かなWebサービスです。

ユーザーを急かしたり、不安を煽ったりすることは目的にしていません。人生が有限であることを、恐怖ではなく愛おしさとして感じてもらうことを目指しています。

## 体験の流れ

初めて訪れたユーザーは、以下の流れを一度だけ体験します。

1. **入口** — 「いつか、今日の何でもない時間を、懐かしく思うかもしれません。」
2. **生年月日入力**
3. **未来の場面** — 少し先の未来の自分から、今の年齢の頃の何でもない一日を思い浮かべる
4. **今日への帰還** — 「今日は、まだここにあります。」
5. **任意のひと言** — 何か浮かんだら残す（書かずに終えてもよい）
6. **終わり** — 「また、いつか。」

生年月日を入力しただけでは初回体験は完了扱いにならず、途中で閉じても続きから再開します。2回目以降（体験を最後まで終えたあと）の訪問では、この一連の体験は表示されず、直接Home画面が開きます。Homeからは「もう一度、未来から今日を見る」でいつでも再体験でき、生年月日の訂正もできます。

## 言語

日本語（`/ja`）と英語（`/en`）に対応しています。`/`へのアクセスはブラウザの言語設定（`Accept-Language`）に応じて自動的にどちらかへ振り分けられ（判定不能な場合は日本語）、画面右上のリンクでいつでも切り替えられます。一度切り替えるとその選択がCookieに保存され、以降はブラウザの言語設定より優先されます。

## 主な画面

| パス | 内容 |
| --- | --- |
| `/ja`, `/en` | 初回：オンボーディング体験 / 2回目以降：Home（今日の記録） |
| `/ja/memories`, `/en/memories` | これまでの記録の一覧 |
| `/ja/about`, `/en/about` | Somedayの考え方とデータの扱いについて |

## データの扱い

ログイン機能はなく、すべてのデータはブラウザの`localStorage`にのみ保存されます（サーバーやデータベースは使用していません）。別の端末には引き継がれず、ブラウザーのデータを消去したり、プライベートブラウズを終了したりすると失われる場合があります。

- `someday_profile` — 生年月日など
- `someday_reflections` — 日々の記録
- `someday_onboarding_completed` — 初回体験を最後まで終えたかどうか
- `someday_onboarding_draft` — 初回体験の途中経過（下書き）

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) をブラウザで開くと確認できます。

```bash
npm run build   # 本番ビルド
npm run lint    # ESLint
```

## 技術構成

- Next.js (App Router) / TypeScript
- Tailwind CSS v4
- localStorage（バックエンドなし）
- `/ja`, `/en` によるルーティングベースの多言語対応（`proxy.ts`で言語振り分け、`lib/i18n/`に辞書）
